# 共享工具与使用入口

[English](runtime-guide.md) | [简体中文](runtime-guide.zh-CN.md)

安装包将公共工具放在 `game-preproduction/runtime/`。从该目录运行 `tools/` 下的命令，将 `--project` 指向实际游戏目录。

| 任务 | 入口 |
| --- | --- |
| 安装、检查与更新 | [安装指南](INSTALLATION.zh-CN.md) |
| 选择工具和配置环境 | [工具索引](../tools/README.zh-CN.md)、[环境准备](../adapters/environment-setup.zh-CN.md) |
| 输入、存档、反馈、交互与导航 | [运行组件](../adapters/engines/runtime_components/README.zh-CN.md) |
| 角色和场景制作 | [资产处理](../adapters/processing/README.zh-CN.md)、[动画播放](../adapters/engines/motion_playback/README.zh-CN.md)、[静态场景](../adapters/engines/static_scene/README.zh-CN.md) |
| 项目看板与资产服务 | [看板](../tools/workbench/README.zh-CN.md)、[资产接入](../adapters/assets/README.zh-CN.md) |
| 模板与格式 | [模板](../templates/README.zh-CN.md)、[Schema](../schemas/README.zh-CN.md) |

[完整文档导航](README.zh-CN.md)。游戏规则、配置、素材与输出保存到游戏项目中；已有游戏通过显式迁移更新组件。
