# 资产迭代计划

[English](README.md) | [简体中文](README.zh-CN.md)

先对真实质量报告执行 `asset_iterate.py draft`，保证问题 ID 对应实际证据。[prompt-plan.json](prompt-plan.json) 演示已确认的门洞问题；路径与观察只是示例，评审标志故意保持未完成。

将草稿复制到游戏项目，选择真实失败或未知项，说明具体调整和预期结果。图像输入路线应替换相关参考并重查对应要求路径，不能添加服务不接收的提示词。观察不确定时使用 `collect_evidence` 和补证任务。命令、参考字段、比较与停止规则见[结果驱动迭代](../../adapters/assets/result-iteration.zh-CN.md)。

输出放在模板目录之外。计划不代表已经生成、加工或验收。
