# 示例限制与注意事项

[English](KNOWN_ISSUES.md) | [简体中文](KNOWN_ISSUES.zh-CN.md)

- 这是工程组合案例，面向 Windows、Godot 与 UE 5.8。不是完整游戏或最终美术。项目行为和资产可独立修改。
- 本例保存房间 a/b、起始房间范围内的角色位置与持物状态；超出范围会明确拒绝保存。不会自动保存任意对象、NPC 路径或正在播放的反馈。读档后 NPC 重新巡逻。
- 本例采用控制器移动与脚/手约束。根运动、转向、分层以及其他导航、交互、存档异常场景沿用各自案例的证据，不能据组合例推断任意排列都通过。
- 按住 E 时丢失窗口焦点会取消交互，恢复焦点后需松开再按。这是输入策略；自动渲染验证期间切到其他窗口也会触发它。
- 音效是原创技术校准音，用于检查生命周期和资源消费，需按游戏风格替换并试听。程序输入不代表真实键鼠/手柄兼容性或热插拔验收；独立使用者接手和人工试玩仍未验证。
- UE 首次启动可能出现角色短暂不可见、着色器编译等待或性能尖峰。请单独检查首次启动、稳定运行和打包后的表现。
- UE 源码需 UE 5.8 和匹配的 C++ 编译环境；Godot 再导出 Windows 包需匹配版本的官方导出模板。已交付 Windows 开发包可直接运行；并非商店发布构建。
- UE 组合示例明确设置 `r.PSOPrecache.ProxyCreationStrategy=0`，避免短暂反馈在默认 PSO 代理延迟期间不可见。这是本例的显示策略，首次创建 PSO 仍可能等待或卡顿；不是共享插件默认值或性能修复。
- 项目组件迁移按文件比较，双方同时编辑同一文件时拒绝整个应用。可捕获的写入错误有恢复路径，断电或强杀不承诺磁盘事务。保留回退 receipt 与项目版本历史。

反馈请使用 TRIAL_REPORT.md，附上实际目标、引擎/工具版本、最短复现步骤、日志与影响范围。不要把程序检查通过写成人工认可。
