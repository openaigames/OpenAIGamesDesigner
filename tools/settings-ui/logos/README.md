# Brand Icon Sources

[English](README.md) | [简体中文](README.zh-CN.md)

These icons identify platforms and services. Brand rights belong to their respective owners.

- `openaigamesdesigner.png`: platform logo supplied by the project owner.
- `tripo.png`: the [48px icon](https://www.tripo3d.com/logo-48x48.png) used by the [official Tripo website](https://www.tripo3d.com).
- `hunyuan3d.png`: the [Apple Touch icon](https://cdn-3d-prod.hunyuan.tencent.com/public/static/favicon/apple-touch-icon.png) used by the [official Hunyuan 3D website](https://3d.hunyuan.tencent.com).
- `elevenlabs.svg`: the [original Symbol SVG](https://11labs-nonprd-15f22c1d.s3.eu-west-3.amazonaws.com/a2ea339b-8b5e-41bb-b706-24eda8a4c9e3/elevenlabs-symbol.svg) from [ElevenLabs brand resources](https://elevenlabs.io/brand), retaining its original proportions and padding. The workbench uses the same file. SHA-256: `84041b5ee800dd3cf5a4f731cda268bdaf5804577c2eba0f60e3aebd18edefb9`.

Icons are stored locally with the settings page; the page does not request images from third parties.

- `bytedance-seed.ico`: the [original site icon](https://lf3-static.bytednsdoc.com/obj/eden-cn/lapzild-tss/ljhwZthlaukjlkulzlp/favicon_1/favicon.ico) from the [official ByteDance Seed model page](https://seed.bytedance.com/en/seedance2_5). Seedream and Seedance share this official mark in both the settings page and the workbench. SHA-256: `734fbc134328bc3a82165d7bc0b53aef8fd32f26446f7209a388c3a0869f0d2b`.
