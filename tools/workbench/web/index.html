版本与参考（可选）

普通生图优先使用当前 Agent 的内置工具。任务保存后由 Agent 执行，结果归入同一版本历史。

默认使用 Seedream 5.0 Pro / Seedance 2.5；可填写兼容的 Seedream 4/5、Seedance 2/2.5 Model ID。

每次生成一张图；宽高比与构图可写在制作需求中。

视频用于过场与预演，不能直接作为角色骨骼动画；最终播放需检查编码兼容性。

该位置应含 start_seconds、end_seconds、play_rate；UE 原生资产可先导出对应配置。

保留原件，副本做裁剪、补静音及短淡入淡出。总时长匹配不代表起音和力度已合格；命中音请单独绑定命中事件。

商用游戏需核对所用账户与音乐授权；普通付费套餐不代表覆盖所有游戏发行用途。

台词按实际文本生成，测量时长后调整文本或表演，不自动裁掉字句。
