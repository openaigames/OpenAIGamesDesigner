# 原型 → 垂直切片 → 制作评审

使用 `templates/milestones/vertical-slice.md` 记录代表性体验、目标品质、制作约束和已有验证依据。没有选定机制时先处理阻塞问题；用户授权探索性制作时明确风险，不制造形式审批。

沿用原生工程，任务按实际需要覆盖玩法闭环、关卡、资产导入、动画/VFX/声音、界面和性能。美术提供可交付规格、来源与视觉检查；技术实现接口/集成；验证把目标关联到实际操作和证据。占位资产与达到品质目标的资产分别标识。

使用与原型相同的执行工具持续运行、回归和记录。先验证可运行，再检查体验、视听呈现、目标环境表现和制作成本；不拿启动成功或截图替代这些维度。

记录真实制作时间、返工和依赖问题，不从预估倒填结果。完成后关联可编辑工程、适用构建、质量证据、剩余问题与取舍。导出未执行或验收未完成时保留缺口。

机制问题返回对应实验；品质问题修改资产/集成；成本问题调整范围。用户以切片为终点时转入交付，无需继续完整制作。


结束本轮实施时回写涉及的专业事实、任务/里程碑状态、证据与管理下一步；失败或中断也要保存。新项目按管理文件约定运行 `validate_records.py --layout --production --closeout --markdown` 并处理结果；只涉及局部资产/功能、已有或自定义结构时检查等价记录，不强制补新作里程碑。检查结构通过不代表验收通过。
