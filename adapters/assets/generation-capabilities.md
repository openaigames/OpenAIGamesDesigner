Tripo model generation uses the V3 API. New H3.1 jobs with textures also pin texture model `v3.5-20260815`. Explicit texture choices and retries keep their original parameters. Local image uploads require PNG/JPEG.

Submission checks validate image views, formats, sizes, and parameters. Check that multiview images preserve the same object's proportions and construction before using them for a subsequent model-generation job.

A local brief does not mean constraint text was sent. Check transmission records and output compliance separately.
