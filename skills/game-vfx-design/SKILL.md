# 特效设计与制作

先说明特效传达的事实：即将发生、正在持续、命中成立、状态改变或纯装饰。读取真实事件与对象、镜头、场景背景和当前问题，避免挥空也生成命中成功反馈。

按 [特效制作与诊断](references/vfx-production.md) 形成形状、节奏、材质与资源方案并制作。预警的范围/时间表达需要和判定共同校准，装饰可以夸张但不能掩盖玩家需要作出的判断。选材可先探索，不凭静态截图判动态效果适配。

解析已有特效时，先追踪渲染器实际使用的资源和有效输出，再区分已确认实现、未追踪的消费者与新提出的设计。保留整套原系统并改参数属于资产派生；从零重建需要交代几何、纹理、材质与曲线的来源。

为每项效果明确局部/世界空间、附着目标、开始/峰值/尾部、独立存活或随对象结束、重复触发和取消清理。武器拖尾读取实际武器路径及启停区间，不能用手部数学轨迹替代实际附件。命中 FX 读真实命中事件，动画播放通知只承担约定的表现时点。

先单独观察效果，再回到代表场景检验叠加、遮挡、噪声和性能。减弱装饰、降低密度或改变构图各有用途，不能把粒子越多当成打击感越强。与动画检查姿态/接触，与音频检查峰值和主次，与程序检查去重、生命周期和清理。

交付实际效果资源/源文件、事件与消费者映射、正常/叠加/取消证据、预算与限制。单效果预览、实际接入、性能与美术品质分别记录；浏览器预览不能代表原生材质最终效果。

取得或制作本轮效果资源后，按 [分类与用途标签](../game-preproduction/references/project-workbench.md#分类与用途标签) 分别归类效果、依赖贴图和模型；特效用途标签与资源主分类分别维护。

## 制作迭代与版本交接

栅格设定图、地图图纸、界面图片或效果概念图的生成工具按 [生成工具选择](../game-art-direction/references/generation-tool-selection.md) 决定；普通生图优先当前宿主可用的内置工具，配置密钥不改变默认选择。

交付物多次修改或使用旧方案时，按 [资产版本与迭代记录](../game-art-direction/references/asset-versions.md) 保留实际文件、修改底稿、参考用途和当前选用。不同专业交付物分别建组，配套文件组成同一版；选回旧版不删除新版本，也不自动覆盖工程、重新绑定或认定验收通过。

本轮实际制作、转换或接入资产时，按 [资产生产登记与交付检查](../game-preproduction/references/asset-handoff.md) 同步维护既有权威清单：沿用稳定 ID，关联源文件、派生物、用途和实际证据。由执行方补齐本轮登记，不把补表留给用户；纯讨论与只读检查不写完成状态。
