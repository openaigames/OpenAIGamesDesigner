# 特效设计与制作

先说明特效传达的事实：即将发生、正在持续、命中成立、状态改变或纯装饰。读取真实事件与对象、镜头、场景背景和当前问题，避免挥空也生成命中成功反馈。

按 [特效制作与诊断](references/vfx-production.md) 形成形状、节奏、材质与资源方案并制作。预警的范围/时间表达需要和判定共同校准，装饰可以夸张但不能掩盖玩家需要作出的判断。选材可先探索，不凭静态截图判动态效果适配。

为每项效果明确局部/世界空间、附着目标、开始/峰值/尾部、独立存活或随对象结束、重复触发和取消清理。武器拖尾读取实际武器路径及启停区间，不能用手部数学轨迹替代实际附件。命中 FX 读真实命中事件，动画播放通知只承担约定的表现时点。

先单独观察效果，再回到代表场景检验叠加、遮挡、噪声和性能。减弱装饰、降低密度或改变构图各有用途，不能把粒子越多当成打击感越强。与动画检查姿态/接触，与音频检查峰值和主次，与程序检查去重、生命周期和清理。

交付实际效果资源/源文件、事件与消费者映射、正常/叠加/取消证据、预算与限制。单效果预览、实际接入、性能与美术品质分别记录；浏览器预览不能代表原生材质最终效果。
