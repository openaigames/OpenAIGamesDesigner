# 战斗特效制作配方

用于已确定的战斗表现返修。先沿 [动态视听制作](vfx-production.md) 找到事件、使用方和时基，再按当前任务问题选用下面的配方。参考画面用于分析形状、节奏和主次；需要复用公网实现时记录作者、原链接、许可证及实际修改，未明确许可的代码/素材不直接收入项目。

## 砂土、裂地和重击：拆层后分别调试

先选一个代表招式，记录落点、方向、范围、峰值和尾部；按层开关比较，避免同时放大粒子、光照、音量和镜头后无法定位收益。下面是制作组成，不是自动生成器或统一美术标准。

| 层 | 制作要点 | 常见失败与检查 |
| --- | --- | --- |
| 地表扰动 | 顺地形的小片破损、凹陷色差和局部裂隙 | 黑色等宽折线像画上去；检查尺度、粗细变化、软边和地表融合 |
| 石块/土块 | 少量有体积碎块，近处较大、远处较小，初速和转动有差异 | 均匀星形尖刺；检查轮廓、重力、落地与材质一致性 |
| 扬尘主体 | 带内部层次的透明贴图/序列，分层扩散与淡出 | 硬边方片、相同烟团平铺；检查 alpha、旋转/尺度变化、亮暗背景 |
| 冲击细节 | 沿速度拉伸的细粒、短亮点、适量火花 | 所有粒子同时等速放射；区分初始爆发和较慢尾部 |
| 短时光效 | 落点或传播前沿的短光脉冲 | 持续泛白遮盖招式；检查范围、衰减和预警可读性 |

向前裂地可用沿路径依次抬起/回落的低面数岩脊，配合向外翻起的土块、沿路径推进的扬尘与短火花。复用旧项目效果时，先拆出材质、生成器、时间轴与事件接口，改用当前地面取样、尺度和预算；不要复制写死的旧场景坐标。

下砸以落点爆发与沿地面扩散为主，前戳突出纵向传播，横扫突出扫过的弧面。血红光芒可作特定招式的附层，但不能把所有攻击都变成同一种全屏爆炸。战吼若没有地表破坏，只保留所需光效与空气扰动。

径向速度感优先用粒子方向、拉伸、层次和短寿命表达；屏幕后处理模糊如需采用，单独限制范围与强度，避免覆盖 UI、预警和瞄准目标。贴图先在实际沙地、雾与光照下审阅，不把黑底预览当作完成。软粒子、深度采样和体积效果按目标渲染器验证；不支持时提供实际测试过的替代方案。

可见传播范围与判定使用同一权威配置，视觉尾部与伤害有效期分开。粒子并发数、透明覆盖面积、灯光和生成/回收开销一起测；低面数不能抵消大面积透明叠加。

## 脚步尘土

由动画触地事件或经过校验的脚掌接触状态触发，不按角色每帧移动就生成。区分脚在地面、腾空、滑动和站立；沿实际地面法线定位，按表面材质选择效果。

以角色尺寸、触地速度和步态决定少量尘团/细粒，脚底接触时形成短峰值，再向后或风向散开。Boss 可更重，但不应每一步制造遮挡玩家的爆炸。暂停、跳时间、传送和重生重置触地历史，避免补发脚步。远距离裁减与粒子池要重置位置、寿命和旧速度。

## 白色武器气流拖尾

在武器实际挥动窗口，采样最终姿态的刃根/刃尖世界位置，连接相邻样本形成带状网格。宽度来自武器段或明确的气流扩张参数；沿长度与年龄渐隐，中心较亮、边缘较软。颜色、透明混合和亮度在实际背景中校准。

按时间和空间距离控制采样，快速转动时适度插值，限制点数与总寿命。样本重复时不生成退化三角形；转折处避免无限延长的接缝。先修武器挂接，再做轨迹，不能用漂亮拖尾掩盖剑穿身体。

明确轨迹历史的生命周期：换武器、传送、换动作、对象销毁和重生清空；一次连续挥击是否跨连段保留由规格决定。顿帧时暂停相关采样/历史推进，不能画出跨越冻结位置的长条；恢复后从有效样本续接。轨迹是表现，不自动作为碰撞判定。

## 对照验收

保留旧失败版本和新版本证据，统一镜头、距离、招式、背景与播放速度。先单层看形状/贴图，再完整组合看节奏，最后进入实际战斗验证遮挡、听感、清理和性能；慢放定位问题，正常速度判断感受。

每项记录源/处理/运行资产版本、目标渲染器、事件时间点、观察与剩余问题。逻辑检查、截图、录屏、实际监听和用户审阅各自说明结果；未通过的裂地或粒子试验可以作为反例，不能包装成已验证的高质量效果模板。详见 [动态视听验收](../../game-prototype-validation/references/audiovisual-validation.md)。
