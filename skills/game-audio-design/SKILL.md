# 音频设计与制作

明确声音承担的信息、情绪与空间职责，再结合实际事件、镜头、监听条件和来源约束选材或制作。素材搜索可以先于完整音频方案，使用时记录来源、版本、格式、用途及编辑过程。

按 [音频制作与实际监听](references/audio-production.md) 设计起音、主体、尾部、循环和层次。击中确认、画外威胁、持续状态与环境底噪需要不同优先级；不要同时提升所有通道响度来补救缺少力度或信息遮蔽。

按 [游戏窗口驱动的音频制作](references/window-driven-generation.md) 从实际事件时序确定目标长度、倍率与尾音，再选材或生成。ElevenLabs 音效、配乐和台词复用现有服务/任务入口；原件、时序来源与编辑副本分别保留，工程窗口变化后重新校准。

为单发/循环/音乐分别定义事件、空间定位、并发/抢占、停止或尾音保留策略。取消蓄力应停止无主循环，独立飞行弹体仍有自己的生命周期；声音不得重复提交规则数值。以同一事件 ID 与动作/VFX/代码交接，保存时基、变速和暂停行为。

实际听代表情境，再检查重叠、重复触发、极端距离、转场与中断；记录设备、音量参考和素材/混音版本。声谱、峰值、RMS 与文件格式可作诊断，不能代替听音；没有音频输出能力时明确听感未验收并保留可播放产物。

交付可编辑源或编辑配方、实际音频、事件/混音配置、监听记录和未覆盖条件。只要求规划时交音频方案与依据；制作任务要接到实际运行使用方，不以一份音效列表结束。

取得、生成或编辑当前任务音频后，按 [分类与用途标签](../game-preproduction/references/project-workbench.md#分类与用途标签) 归入音乐音效，并在有依据时细分配乐、音效、配音；角色用途标签与音频分类分别维护。

## 制作迭代与版本交接

交付物多次修改或使用旧方案时，按 [资产版本与迭代记录](../game-art-direction/references/asset-versions.md) 保留实际文件、修改底稿、参考用途和当前选用。不同专业交付物分别建组，配套文件组成同一版；选回旧版不删除新版本，也不自动覆盖工程、重新绑定或认定验收通过。

当前任务实际制作、转换或接入资产时，按 [资产生产登记与交付检查](../game-preproduction/references/asset-handoff.md) 同步维护既有权威清单：沿用稳定 ID，关联源文件、派生物、用途和实际证据。由执行方补齐当前任务登记，不把补表留给用户；纯讨论与只读检查不写完成状态。
