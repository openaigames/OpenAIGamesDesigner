# 按游戏事件窗口制作音频

从实际玩法时序提出声音需求。读取工程事件、动画 Notify、动作配置及代表性运行记录，明确时基、起止、倍率、触发者、停止条件和可保留尾音。先取得窗口再搜索、生成或编辑素材；不要为了迁就已有音效任意改变玩法节奏。

挥动窗口、命中确认、动作全长是不同依据。挥动音随动作事件触发；接触/破防声随真实判定触发；蓄力、状态循环与飞行物由所属对象管理生命周期。短挥动也可以有延续的空间尾音，主体时长与允许尾音分开，不要求一切声音恰好等于判定窗口。

固定动画倍率下，主体实际时长为 `(结束 - 开始) / 倍率`。已是运行实际秒的数据使用倍率 1，避免重复缩放；变速曲线、暂停、hit stop 和时间膨胀通过引擎实测与播放策略验证。不能从 clip 全长猜声音窗口，也不能把手填时间称为已和工程绑定。

模型选择遵守 [最新旗舰模型策略](../../../adapters/assets/model-defaults.md)：新台词、配乐、音效按各自产品的旗舰型号准备，历史素材的模型 ID 不作为新任务的默认选择。

用户选 ElevenLabs 时，复用运行工具包 `adapters/assets/elevenlabs-audio.md` 的适配器、服务配置和资产任务；不要新建另一套凭据存储或看板。它支持音效、配乐、台词。生成前将具体描述、事件、目标长度、来源版本、参数和费用交给用户在已有任务页核对授权。保存 Key 不等于授权收费生成，失败不自动重试。

音效可绑定项目内 JSON 窗口：提交保存配置快照，执行前检查来源哈希；变化后重新准备。UE 原生资源先按实际工程导出窗口，保留资源路径与版本依据。服务最短时长大于游戏窗口时，请求支持的长度并保留原件，再按试听选定的截取起点制作副本；不要默默加长游戏窗口。生成时长是请求约束，不是精确音频起音或峰值保证。

副本保留裁剪/补静音/淡入淡出配方，不默认通过改速改变音高，不静默压缩整段声音。先听原件与副本，再按需重新编辑。检查瞬态是否完整、主体力度、尾音自然性、循环接缝和并发遮蔽；阈值、波形、时长、RMS、峰值不能替代听感。短文件补成等长可能只有静音，仍需返工。

台词先调整文字、停顿和表演，避免按窗口硬裁字句。配乐长度、段落和转场按战斗结构设计；生成一段配乐不等于自适应音乐完成。分别核对所选产品与账户的来源许可，尤其游戏商业发行的音乐权限。

最终在实际游戏镜头下监听挥空、命中、变速、取消、死亡、暂停与恢复。交付原件、使用版本、来源/许可记录、时序配方、事件使用方与实际监听结果。自动测量只标记测量完成，不自动标记听感或游戏接入通过。
