# 音频制作、混音与实际监听

## 选材与编辑

从听觉职责、风格、事件长度和视距选择素材，先实际播放再比较。列表标题、波形或网站描述不能证明声音适合。按本项目来源约束检索，保存源文件、来源/许可、裁剪/处理与导出设置；没有制作能力时不能把待找音效表报成成品。

起音传达时点，主体传达材质/力量，尾音传达空间与持续。分层让这些职责可独立调整，但过多层可能模糊起点和空间定位。音高/随机变体应保持事件辨识和主节奏，不能靠极端变速掩盖不匹配素材。

## 事件、循环与空间

离散事件、持续状态与音乐段落分别定义触发/停止。音效读实际命中/状态事件，不能靠播放结束提交伤害。循环检查无缝边界、停播尾部和所有者销毁，音乐检查进入/退出条件和衔接；仅测试循环单段不能证明战斗转场自然。

空间衰减、遮挡与屏外提示服务玩家理解。源位置、相机/听者位置和视觉对象可能不同，选择要明确；不能把所有声音都设为非空间化以解决听不见。预警、玩家反馈、环境和音乐有优先级，按同屏高密度情境决定并发、抢占及 ducking，而非每次叠加都提高响度。

## 监听与因果定位

记录设备、音量参考、构建、资源版本和操作条件。先比较原始资源，再听运行事件、距离和整体混音。响度、峰值、频谱、RMS 可帮助发现削波、低频堆积或静音，但听感与信息识别须实际听；不宣称没有听过的声音“更有力量”。

打击感不足先核对实际命中到声音起点的关系，再分开调整起音、音色/层次、被击响应和其他反馈。声音提前可能制造未命中的错觉，过长尾音会遮盖下次输入/预警。比较时注明游戏变速是否影响音频和实际时钟。

检查重复触发、同时命中、失焦/暂停、取消、角色销毁、场景切换与重试。保护应持续的独立对象音，清理失去所有者的循环；不能一键停掉所有声音来掩盖状态错误。

交付原始与处理后音频、编辑配方或工程、事件/混音配置、真实监听片段和具体结论。未能监听的部分保持未验证，自动检查通过只说明其所测量的技术条件。

## 制作实例：连续击打盖住敌人预警

先分轨导出命中瞬态、材质主体、空间尾部和敌人预警，保持同一参考音量监听单轨及混音。记录预警在何种击打密度下开始失读。若低频尾部持续堆积，优先缩短或衰减尾部、限制相同事件并发；若瞬态遮盖预警，则尝试对低优先级命中做短时 ducking。每种调整都回听清晰度和力量损失，不默认提高预警增益。

制作步骤为裁剪无用前导静音、保留起音、修复循环接缝/必要淡入淡出、按项目峰值与响度范围调整、输出原采样率或明确重采样版本，再在引擎测试。保留无处理源和处理配方，避免重复压缩不可逆叠加。3D 音源需从听者近/远/背后以及遮挡边缘实际试听；耳机与扬声器结果分别记录。

取消持续蓄力时停止所属循环或进入约定 release，短命中尾部是否保留单独决策。重复通知、暂停、销毁和重试不能留下无主音源。自动生成波形、测 RMS/峰值或发现 AudioStreamPlayer 正在播放只能证明这些技术事实；最终交付需要实际监听记录，监听不可用时不能把听感结论补成通过。

## 音效：事件一次与文件一次分别检查

| 事件 | 播放与生命周期 |
| --- | --- |
| 实际挥动 | 挥舞声，命中和挥空都会有；按段选择，不每帧播放 |
| 确认命中且结果需要 | 血液/材质接触声，与相应血花或火花一致 |
| 角色死亡进入 | 死亡提示/落剑声以本次死亡实例去重；重生后允许下一次死亡 |
| 地名出现、胜利、失败 | 以实际播报事件触发同步声；关闭/重播遵守同一实例规则 |
| 移动或战斗环境 | 循环声有明确所有者、循环点、退出/淡出与尾部策略 |

落剑声听起来重复，先查看事件触发次数、播放实例和循环设置，再单独试听源文件。有些素材本身包含多个撞击或一组变体；仅增加代码去重无法消除文件内的多次声音。需要裁切时保留源，建立派生片段与切点记录，避免切断自然尾音。

招式吼声按具体动作与节奏分配；限制连续重复和同时人声数量，不把每次挥舞都配同一声吼叫。击杀、处决与背景音乐的主次通过混音试听确定。

音乐音量没有适用于所有素材的固定 dB 值。区分音源响度、播放增益、总线电平和真实监听音量；以项目代表战斗混音为基准，检查削波、提示可听性、循环接缝与转场。没有实际监听时只报告文件与数值检查，不填写“听感通过”。
