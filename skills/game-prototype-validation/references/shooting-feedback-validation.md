# 射击反馈验证

用于后坐、枪摆、镜头、准心及动作过渡变更。先核对 [效果定义](../../game-combat-design/references/shooting/recoil-and-presentation.md) 中的实际规则，不默认存在所有效果或玩法。

## 能回答问题的对照

固定武器、射速、机位、距离、姿态和输入，逐层开关，再观察组合。选择单发、短点射、连射、停火、压枪/过量补偿、腰射/开镜及实际支持的中断。软件输入可检查重复性，不能代表真人操作和舒适度。

| 检查 | 证据与边界 |
| --- | --- |
| 纯视觉层隔离 | 相同输入与随机种子下，比较实际射击时间、原点、方向、命中及资源；仅比较函数返回值不足以排除遮挡副作用 |
| 规则后坐生效 | 开关影响所声明的瞄准基准；不得只证明模型移动 |
| 瞄具与射向 | 同帧采样实际武器姿态、前后瞄具或瞄准标记、渲染投影和真实射线；按归零距离/散布声明解释偏差 |
| 压枪与恢复 | 分别检查无输入、部分补偿、完全补偿和反向输入；记录停火后是否意外下沉或回拉 |
| 过渡与打断 | 比较规则允许开火/装弹提交时点和动画表现；检查奔跑退出、换弹打断、切换和重复触发 |
| 帧率与随机 | 代表性帧率下比较峰值、恢复及发射节奏；关闭视觉层不应改变弹道随机序列 |
| 视听与品质 | 实际播放检查握持、遮挡、连续性和音画时点；音轨存在不能代替监听，自动规则通过不能代替用户手感认可 |

阈值由项目的单位、镜头、交战距离和目标决定，记录依据，不给所有项目套固定像素或角度标准。真实运行日志和视频注明构建、配置、层开关、操作者及未测范围。改动后只回归受影响行为，保留旧失败和旧版本证据。

多人同步只在有实际两个客户端/服务器观察时判定；单机第一/第三人称切换只证明本机表现。没有执行的监听、真人试玩或网络测试保留未验收。
