# 资产与动态视听验收

用于确认素材是否满足具体用途，或定位“看不清、动作不顺、声音残留”等反馈。以认可的资产规格、真实文件、消费者和代表场景为输入；尚未选择风格时可以比较候选，不能先批准最终品质。

## 按证据层逐步定位

| 层次 | 怎么检查 | 不能据此证明 |
| --- | --- | --- |
| 源文件 | 用支持格式的工具打开，核对尺寸/通道/依赖、动画或音频内容 | 引擎导入和运行正确 |
| 导入资源 | 核对设置、标识、材质/骨架/图集/循环与重新加载 | 目标场景中的可读性和性能 |
| 实际消费者 | 使用真实镜头、挂点、缩放、背景与监听条件 | 其他场景或目标平台同样通过 |
| 动态与压力情境 | 按事件运行，检查中断、叠加、视角变化及目标负载 | 所有内容组合均已覆盖 |

每层可从问题所在处开始，不要求普通图片替换都完成全套平台验收。

## 选择能暴露问题的条件

2D 资产检查实际缩放、图集边界、透明边缘、帧锚点和前后景遮挡；3D 检查不同距离、变形姿态、材质槽与碰撞/外观一致性。代表动作至少覆盖本轮需要的正常和取消/失败路径，记录信号与可见结果。

VFX 检查背景亮暗、同屏叠加、出入视野、挂点/所属对象销毁与循环结束。关键预警是否被其他反馈覆盖，要在实际战斗或活动密度下观察，不只打开独立预览窗口。

音频需要实际监听，注明设备、音量设置和其他声部条件；检查播放、循环、转场、停止、并发及主次。文件存在和波形正常不能证明可听性或混音合适；峰值、响度或频谱只支持相应技术指标。无法播放时只报告文件层检查。

## 假设例：取消蓄力后仍有嗡鸣

保留同一构建，在进入蓄力后分别正常释放、提前取消和对象销毁，记录输入时点与声音变化。先确认取消事件是否发生，再查循环声所属实例与停止信号；若规格允许短尾音，应区分尾音与无期限循环。不能为消除残留直接停止场景全部声音而漏掉正常背景音回归。

结果写具体对象、版本、条件、期望、观察和证据时间点。返修指向事件缺失、导入设置、资源内容或层级问题，而不是只写“质感不足”。固定截图可以对比轮廓，录屏支持时序，监听支持听觉；未经真实观察的部分保持未验。

最终报告分别列文件可用、导入正确、表现符合本轮目标和未测条件。生成工具的 succeeded 或资产哈希一致只证明产物记录，不能填写这些验收结论。
