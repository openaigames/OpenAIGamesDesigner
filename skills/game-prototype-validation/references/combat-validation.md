# 战斗验证与回归

具体预期计算、临界窗口和结果归因使用 [数值与时序](balance-and-timing.md)；动画/VFX/声音的实际观察使用 [视听验收](audiovisual-validation.md)。本篇负责按变更选择战斗检查范围。

从本轮动作规格、改动和实验问题确定检查，不把全量列表作为每次任务门槛。关联设计/配置、代码/资产版本及可重复的场景、初始状态与操作。

功能检查按需覆盖：正常激活与命中、无效目标/未命中、资源不足、连续输入、重复命中、冷却、取消、受击打断、死亡、装备/角色切换。结束后观察资源、状态、监听、位移和表现是否符合规则；不要预设取消一定退款或死亡一定能打断。

时序检查区分前摇、生效、后摇与取消窗口；记录帧率/时间单位，动画变速和实际判定方式。自动断言针对规则结果，录屏或实际操作支持呈现观察，两者不互相替代。

体验验证记录操作任务、操作者/参与者、提示干预及观察；“命中正确”不证明节奏或反馈满意。表现检查关注预警/命中的可读性、声音与中断清理。测试场可有重置、木桩、参数和状态显示，但只建设本次需要的能力。

联网项目增加权威与客户端结果、预测校正、重复应用和实际延迟条件；单机记录不能作为联网通过证据。性能测试注明硬件、场景负载、配置及采样方式。

沿用已有记录，必要时使用工具包 `templates/validation-report.md`，按本参考补充战斗时序、数值和表现等实际检查。发现问题回到相关设计、资产或实现任务，不自动重置全项目阶段；原型机制结论和切片品质验收分开。
