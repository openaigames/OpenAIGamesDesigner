# 敌人、Boss 与遭遇设计

用于新增敌人、敌人能力、Boss、战斗组合或调整场景压力。先理解玩家已有应对、目标和空间；敌人不是只有不同血量和技能列表的容器。

## 从玩家决策定义敌人职责

说明敌人让玩家关注什么、改变什么选择，以及玩家如何识别和应对。可涉及距离、位置、目标优先级、时机、资源或协作；不强制所有项目都有“坦克/输出/治疗”等分类。

一个职责至少关联一种可观察行为。例如迫使玩家离开安全位置，需要可理解的区域威胁、接近压力或目标变化；只增加敌人伤害未必产生位置选择。敌人差异也可以来自信息与空间，不一定新增系统。

## 职责与角色素材

职责已定时，将其转成必要行为与玩家应对要求再找模型、动作或装备；职责/招式尚未定时，可先搜索并检查可用组合，根据实际能力提出敌人方案。两种入口都要把动作落实为可读信息、应对选择和反击收益，不把玩家装备直接复制给敌人，也不把源包招式列表当作完整 Boss 设计。按 [角色职责与素材适配](../../../game-art-direction/references/role-asset-fit.md) 判断适配；方案采用或发生变化后，批量制作/正式接入前更新行为规格并复查预警、范围、恢复与反击机会，不必重写无关系统。

## 行为规格与反制机会

| 内容 | 需要交接的设计 |
| --- | --- |
| 感知与信息 | 敌人何时知道玩家的位置/状态，失去信息后怎样处理 |
| 意图与选择 | 在什么条件选择行动，多个合法动作如何取舍，选择何时更新 |
| 接近与站位 | 希望处于什么关系，路径不可达或距离不符怎样处理 |
| 招式 | 预警、追踪/锁定时点、生效、恢复及动作规格引用 |
| 玩家应对 | 有哪些实际可用选项，失败信息和成功收益是什么 |
| 特殊状态 | 受击、控制、失去目标、脱战、死亡等适用行为 |

设计说明可用条件、权重意图、限制与例外，不必预先决定行为树或状态树等实现架构。随机选招仍需检查组合、连续重复和极端序列，不把“随机”当作变化充分或公平的证明。

提示 → 识别 → 决策 → 执行之间要留出与目标相符的机会。所谓可应对不能只在静止木桩上成立：玩家可能在动作承诺中、镜头被遮挡、正应对其他敌人，或者缺少某种资源。是否允许无解局面以及它是否可提前避免，需根据目标明确。

## 遭遇是组合关系

先定义场景目的和胜负/结束条件，再选择敌人、数量、位置、进入顺序、环境、补给和退路。相同敌人在开阔地、狭道、掩体和高差中造成的压力不同。

分析同时施加的任务：移动、观察、瞄准、打断、保护目标等是否互相兼容。远程封锁和近战追击可以产生取舍，也可能完全封死应对；多个各自可躲避的攻击不保证组合后仍有机会。必要时使用攻击协调、进入节奏或空间限制作为候选，不把实现方式当成普适答案。

区分压力建立、峰值、缓解、重新定位与收尾。波次只是组织方式之一，不因模板要求给所有战斗设计波次或强制计时。用场景说明或布置草图支持分析，而不是只给敌人清单。

## Boss 按需要增加的层次

Boss 需有招式之间的选择关系、玩家学习与利用的机会；高血量和阶段数不是质量指标。阶段变化说明触发、过渡、保留/清除状态和新规则的告知方式。

阶段切换与连续伤害、正在执行的技能、召唤物、持续效果及死亡的先后关系要明确。控制免疫、弱点暴露、破防等仅适用时添加，保证例外可被理解。记录重试入口与恢复条件，避免观察被长时间重复准备掩盖。

## 示例与交付

示例：一个敌人迫使玩家移动，另一个奖励玩家停留瞄准。二者组合可能形成时机选择；若前者持续无间隙施压，后者只能用长时间静止瞄准击败，且没有替代应对，则两条要求可能冲突。应比较进入节奏、攻击间隙、掩体或可替代反制，而不只降低总血量。

交付敌人职责、行为/招式与玩家应对关系、适用例外、遭遇布置与节奏、测试预设和风险。技术侧实现决策与能力，美术侧表达意图，验证侧观察真实应对与组合压力。需要空间分析时读取 [controls-and-space](controls-and-space.md)。

## Boss 招式池与决策边界

先实际审阅动作，把主动攻击、移动、战吼、受击、倒地、处决与死亡分开。名称中含 attack/combo 不能证明它适合作为主动招式；保留候选不等于已配置成技能。

沿用既有 AI，将职责解释清楚即可，不要求重建框架：

1. **观察**：何时获得距离、朝向、视线和目标状态。若目标体验不允许读输入，使用可感知的动作/位置和明确延迟，不能直接针对玩家刚按下的键选克制招。
2. **合法性筛选**：阶段、距离、高差、空间、冷却、当前状态和素材就绪。没有合法攻击时，选择接近、重定位或等待等有效行为。
3. **选择**：在合法集合内按职责、近期重复、距离偏好和冷却取舍。保留可重放的随机种子/选择原因用于调试；随机不等于公平。
4. **执行**：前摇、朝向追踪截止、生效、连段节点和恢复。连段只在允许节点续接，已承诺攻击不因每帧重新评分而变招。
5. **反应**：受击、目标丢失、阶段切换、处决和死亡按已定义优先级打断；清除未执行分支，不能恢复后补打一招。

示例：Boss 在高台等待接近，入场触发后才进入战斗；等待状态不能同时使用追击逻辑。玩家死亡后停止对其选择攻击，胜利动作/声音只触发一次。脱战与重试需要复位冷却、反应、招式序列与接管状态。
