# 后坐、枪械运动与瞄准表现

用于射击手感分层、术语核对、后坐调校和瞄具/落点不一致问题。选择当前项目需要的效果，不要求每个项目采用全部层，也不默认加入随机散布或辅助瞄准。

## 按行为定义效果

英文名称在不同项目中含义不一。先读取现有实现，并用以下行为与影响范围说明；变量名不能代替定义。

| 工作名称 | 作用 | 射击规则 |
| --- | --- | --- |
| 视角后坐 View kick | 发射引起瞄准视角偏转，镜头呈现该偏转 | 改变后续发射的瞄准基准 |
| 武器瞄准偏移 Gun kick | 武器瞄准方向相对视角偏转，瞄具与射向读取同一偏移 | 改变瞄准基准；与纯视觉运动分开 |
| 纯视觉枪械后坐 Visual recoil | 模型后移、旋转或振动 | 不改变权威发射原点、方向或资源状态 |
| 纯视觉镜头扰动 Camera shake | 在基础视图上叠加位置/旋转扰动；View roll 是绕视线轴旋转的子类 | 不改变权威瞄准；需核对渲染投影与提示 |
| 散布 Spread | 对每发弹丸施加分布偏差 | 改变实际弹丸方向，与后坐独立 |
| 持枪随动 Sway / Bob | 转向、走跑、呼吸、着地驱动的武器运动 | 先声明仅表现或参与精度，不能隐含影响 |

纯视觉层仍可能遮挡目标、移动瞄具或改变玩家感知，不能把“不改射线”称为“不影响瞄准体验”。如果装饰性枪口位置参与近墙阻挡或发射原点计算，也需拆出稳定的规则挂点，或者明确记录这项玩法影响。

## 效果与实现机制分开

动画、时间曲线、弹簧、固定序列与受限随机是实现手段，可以组合。干脆、厚重、振荡等是体验目标，不是固定算法或通用参数。先做一套可理解的基线，再派生当前项目需要的预设。

每个启用效果记录：使用方和作用空间、单位/轴向/旋转支点、触发事件、幅度与限幅、进入/峰值/恢复时间、连发累积/重触发/停火行为、玩家补偿与状态切换处理、腰射/开镜等适用状态、与其他层的叠加顺序。简单效果只填实际相关项，沿用项目现有配置格式，不建立第二份参数主源。

视角恢复与压枪补偿共同设计：无输入自动回位、补偿后保留新的基准、只恢复未补偿部分、保持后坐不回位都是可选规则。记录选择并检查反向输入、过量补偿及停火，不让恢复与输入两次抵消同一偏移。随机散布和随机视觉效果分开随机源，关闭纯视觉层不应改变后续弹道随机序列。

## 运动与瞄具校准

前后位移、抬枪、左右摆和滚转分别调节。按握持与受力选择抵肩、握把、手腕或支架支点；不同武器不强制共用。写明局部/父级/世界空间及变换先后，避免在脚底骨架原点旋转整套手臂。

规则瞄准方向是主源；模型瞄具和准心按当前镜头投影校准。需要有限距离归零、弹道下坠或近墙遮挡时明确适用距离与偏差。动画枪口并不天然是稳定射击基准，不能未经校准就直接让其每帧轨迹决定命中。

开镜需独立检查屏占比、前后瞄具关系、视觉扰动和灵敏度/FOV变化。允许有意的视觉偏差，但须可解释并记录，不用中心准心掩盖瞄具偏离问题。

## 动作与事件协同

奔跑退出的移动减速、持枪回位、允许开镜和允许开火是独立时间点。支持的输入组合与打断按现有状态系统定义，不能用一个混合时长代替全部规则。

换弹的装弹生效、可开火与动画收尾分别约定；第一/第三人称可分别制作，共享动作语义与关键事件。整体拉伸到相同时长不证明弹匣接触或机械动作同步。音效、HUD和特效订阅对应事件，明确连续触发时重启、叠加、保持或替换，不重复提交资源/伤害。

## 选择与验证

表现设计依输入设备、竞技信息需求和视觉方向选择。平台输入加速、特定引擎刷新行为或未证实的拆解结论，不作为普遍规则。工具包提供方法，不固定具体作品、枪型或表现模板。

实施与检查分别见 [技术接入](../../../game-technical-design/references/shooting-feedback-integration.md) 和 [射击反馈验证](../../../game-prototype-validation/references/shooting-feedback-validation.md)。独立安装时沿用本页的行为、事件和空间约定即可。
