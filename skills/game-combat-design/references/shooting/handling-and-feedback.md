# 射击操控与反馈

用于武器/发射工具手感、后坐、散布、稳定性与反馈。先定位用户说的“飘、轻、慢、不准”对应哪个可观察环节，再决定修改规则或表现。

## 分开相关机制

瞄准方向变化、实际发射方向变化、随机散布、镜头位移和视觉模型动画可能相互关联，但不能视为同一个参数。说明哪种变化影响下一发，哪种仅表达反馈，恢复如何发生；不要让准星显示保证精度而实际判定使用不同范围。

按需定义连续发射累积、恢复条件、移动/姿态/瞄准影响、输入补偿与切换后状态。随机偏差、固定模式和可学习变化产生不同要求，选择依据应来自目标。没有精度压力需求的工具可以不引入这些机制。

## 反馈表达什么

区分输入被接收、可以发射、实际发射、途中变化、命中、未生效和结果确认。声音、动画、VFX、准星或触觉按设备需要表达这些事件。是否需要命中提示由可读性和信息设计决定，不机械要求显示所有隐藏结果。

检查高频、长时间和密集使用时的可读性、疲劳与遮挡。增大镜头抖动可能增强瞬间力度，也可能破坏目标跟踪；提高反馈强度不能修复实际输入延迟。表现改动依用户范围处理，不自动改变伤害或弹道。

## 代表分析

若“准星还在目标上但连续射击越来越偏”，需核对准星表达、散布来源、射向变化和恢复，不能直接认定玩家操作错误。若结果正确但感觉没有命中，可能缺少合适的结果反馈，不能据此提高命中范围。

交付操控变化与实际发射的关系、表现事件/资源需求、可调参数来源、正常及边界场景。比较候选时记录设备、镜头、距离、输入与速度条件；真实操作、画面/声音检查和功能测试分别报告。
