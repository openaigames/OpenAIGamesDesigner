# 历史采样适配器

`assets/rift-baseline/RiftBaselineCapture.h/.cpp` 是旧 Rift Duel 工程的 `/1` 基线采样参考，保留路径以兼容历史记录。它不是可独立编译的插件，也不是新工程的创建模板。

该代码依赖原工程的 `RiftCombatant.h`、`RiftWeapon.h`、ARiftPlayer、武器枚举及相关战斗规则；这些业务实现不随工具包提供。缺少对应原工程时，只能参考采样方法，不能把这两个文件复制到普通 UE 模块后声称已完成接入。

它在骨骼和武器实际求值后采样，有意关闭角色整体位移与 Boss AI，记录特定单招/连段基线；其中骨名、剑/锤分类和挂接偏移只描述旧工程事实，不能作为其他角色的默认绑定或根运动依据。

当前任务优先使用 [运行管线](running-the-pipeline.md) 的共享会话与 `/2` 实际消费者采样。需要复现 `/1` 时，应显式提供目标工程、模块、角色资源和采样入口；不得补造未随包提供的业务类来伪装可运行。通用测试场仍位于 `assets/unreal/`，与此专属采样代码分开。
