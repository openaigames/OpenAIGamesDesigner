# 验收与工程接入

| 层次 | 证据 | 不能据此推断 |
|---|---|---|
| 工具可用 | 脚本实际运行、文件可读、退出码和日志 | 动画完成 |
| 回传一致 | 同时间/骨架的位置与旋转误差；根骨、层级、单位一致 | 原动作没有穿模 |
| 绑定与运动 | 真实蒙皮/武器，多视角、正常/慢速/逐帧，单招和连段/取消 | 主观打击感满意 |
| 游戏接入 | 真实输入、唯一伤害提交、取消清理、位移不重复 | 所有内容和帧率组合通过 |
| 体验 | 操作者、条件与反馈，动画/目标响应/VFX/声音/镜头按项对比 | 未测用户或平台也满意 |

先无 FX 看完整动作，再逐项恢复反馈。短片覆盖动作前后与连段接缝，不能只截漂亮的命中帧。固定步长用于可重复取证，不是稳态 FPS 证据。

粗版本可以在已有授权和明确占位范围内接入玩法实验，不等待全套精修完成；报告仍保留“原型/未完成品质验收”。精修候选的资产证据不替代真实输入、目标响应和同屏反馈测试。纯 UE 资源检查不强制先导出外部源，按实际分支记录导入或回传证据。

每个缺陷写“版本 / 首次时间 / 视角和速度 / 期望 / 实际 / 归因层 / 修改 / 复测”。区分姿态、挂点、导入缩放和事件偏移，不能一概称为质感不足。

已有授权范围内继续接入达成当前任务标准的候选，不给每个文件增加确认。如果用户只要求管线，交付候选计划，不自动覆盖原游戏动作。

绑定约定：动作 ID → 实际 AnimSequence/Montage/层 → 播放率 → 事件时基 → 位移主驱动 → 唯一伤害提交方 → 正常/取消清理。Notify 可以开窗口，不能仅凭动画播放扣血或重复结算。

先替换一条代表链路，检查输入、起/收招、混合、接触、受击/闪避取消、死亡/重试，再扩展。保留旧引用与回滚记录。源动作、绑定、压缩、重定向或导入设置变化，使对应证据失效后局部复测，不重跑无关全项目检查。

枪械动作与程序化运动叠加时，按 [后坐与表现定义](../../game-combat-design/references/shooting/recoil-and-presentation.md) 核对支点、空间和事件。分别检查原手臂/武器动作与程序化层；第一/第三人称关键时点需实际比对，播放总时长相同不代表接触同步。
