# 动作制作与问题定位

从实际规则确定攻击意图、支撑脚、受力方向、接触部位、收招承诺和接续位置。时序用秒与帧并列，注明源帧率和运行变速；前摇、接触、随动、恢复、接招与取消不是同一概念。

先摆出进入、蓄力、接触、随动、恢复等必要姿态，不限制关键帧数量。侧面检查武器和重心是否真到目标，正面检查肘/肩/手腕扭曲与身体穿插，游戏镜头检查动作方向和下一次危险信息。关键姿态成立后再处理曲线。

| 反馈 | 先找的证据 | 归因候选 |
|---|---|---|
| 武器穿身 | 实际蒙皮与武器，正常/慢速、多视角，首次穿插帧 | 姿态、肘方向、武器弧线、扭转骨；之后才是细微挂点调整 |
| 手柄错位 | 手掌接触点与柄上标记；区分腕骨原点与掌心 | 握持校准、指部姿态、辅助手目标、IK 权重区间 |
| 整体位置错误 | 同参考姿态、单位、根骨、轴向与使用方变换 | 坐标链；避免多处补偿 90° 或 100 倍缩放 |
| 连段抽动 | 前招真实切换帧到后招起始帧的手/脚/骨盆轨迹 | 入/出姿态、曲线、混合、缓冲切换 |
| 脚滑 | 作者标注的支撑区间、地面与根位移 | 根运动所有权、步法；腾空/换步不算脚滑 |
| 未接触却扣血 | 武器轨迹、目标体积、判定窗口与伤害提交时间 | 动画接触与规则范围协调，不只把特效做长 |
| 没有力度 | 蓄力/挥出速度对比、随动、目标响应、停顿与声音起点 | 先动画与接触，再逐项加入响应、声音、镜头做 A/B |

源场景保留控制与约束，导出副本烘焙。只导出目标 Action，避免无关 NLA/Actions。绑定记录主手/辅助手标记与启用区间；腕骨误差为零不证明手指自然握柄。

根位移只有一个主驱动，记录 CharacterMovement、Root Motion、Motion Warping 的职责和顺序。重定向先校准参考姿态/骨链，再核对接触；骨名匹配不代表比例合适。

Combo 必须观察真实混合/换武器/取消位置，不能用两招各自正常播放证明衔接。候选动画源可以验证姿态，接回游戏后仍需回归输入、中断和迟到事件。诊断阈值要按角色比例和动作意图校准，不是统一行业标准。
