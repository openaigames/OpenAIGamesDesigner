# 角色与装备美术

以对象职责、已有风格、镜头距离、动作/装备要求和来源约束为输入。可以先搜索和观察真实素材，再提出造型/玩法组合；候选模型图片只证明可见造型，不证明骨架、动作或握持可用。

新制或替换需要动画的模型，先按 [动画与骨架路线](../game-technical-art/references/rig-aware-asset-production.md) 确认是先定模型再绑骨配动作，还是依据已有动画/骨架制作模型；已选路线和风格直接沿用。后者先取得实际比例与接触依据，再形成提示词、长度注释及必要参考图，生成后校准网格并绑定指定骨架。不要以平台能自动绑骨为由默认替用户选择。

按 [角色制作与适配](references/character-production.md) 依次处理决定性风险：轮廓和比例、装备尺寸与接触、变形区域、材质阅读、近景细节和性能。已有原包先保存原始预览与文件版本；不要把接入错误归因于作者资产，也不默认修改原件。

选材或制作要交付实际文件及来源。下载、生成和程序制作均关联对象、用途和局限；免费/付费、许可和预览偏好来自本项目约束。若某候选动作缺口改变角色能力，与战斗/系统一起调整方案或换候选，不用大幅 IK 偏移掩盖结构冲突。

美术指导提供整体风格，本 Skill 完成角色和装备资产；TA 校准骨架/蒙皮/轴向与技术规格，动画验证接触及连续动作，程序使用明确附件。角色身体、武器握柄、挂点和运行对象的关系共用一份来源记录。

在目标镜头、代表动作与实际场景光照下检查，不能只交转台截图。交付可编辑源、引擎资源、制作规格、来源/改动边界和实际观察；技术导入、变形质量、视觉适配分别判断。仅设计任务可交造型规格与依据，不能宣称模型已经完成。

下载、生成或制作本轮角色与装备后，按 [分类与用途标签](../game-preproduction/references/project-workbench.md#分类与用途标签) 补齐文件分类；身体、武器、贴图分别归类，“主角”等用途标签继续共享。

## 人物设计图与生成输入

制作人物设计图或准备三维生成时，按 [人物参考图与交付范围](references/character-references.md) 核对本次需要的全身、双臂或附件，检查多视图的姿态、方向与构造，补充关键部位的厚度依据，并标清设计图、实际发送图片和模型截图。按已选用途准备，已有明确方案不重复询问。

## 制作迭代与版本交接

栅格设定图、地图图纸、界面图片或效果概念图的生成工具按 [生成工具选择](../game-art-direction/references/generation-tool-selection.md) 决定；普通生图优先当前宿主可用的内置工具，配置密钥不改变默认选择。

交付物多次修改或使用旧方案时，按 [资产版本与迭代记录](../game-art-direction/references/asset-versions.md) 保留实际文件、修改底稿、参考用途和当前选用。不同专业交付物分别建组，配套文件组成同一版；选回旧版不删除新版本，也不自动覆盖工程、重新绑定或认定验收通过。

本轮实际制作、转换或接入资产时，按 [资产生产登记与交付检查](../game-preproduction/references/asset-handoff.md) 同步维护既有权威清单：沿用稳定 ID，关联源文件、派生物、用途和实际证据。由执行方补齐本轮登记，不把补表留给用户；纯讨论与只读检查不写完成状态。
