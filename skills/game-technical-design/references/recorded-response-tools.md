# 记录与比较操作响应

动作时间轴使用动画技能的 [通用事件工具](../../game-animation-pipeline/references/action-timeline.md)。射击、移动、近战与交互的事件由项目配置；不要把通用工具固定成枪械状态机。

`scripts/response_compare.py --spec 比较配置.json --captures 记录一.json 记录二.json --out 新报告目录`

本工具只测量已有运行记录，输出 JSON 与曲线 HTML。使用同一输入、镜头、距离、射速等条件；输入和条件不同会标明无法直接比较。不要为了让检查通过而填写未经执行的相同输入。

比较配置：

```json
{
  "schema":"response-comparison/1", "recovery_dwell_s":0.1,
  "channels":[{"key":"yaw","unit":"deg","layer":"weapon_direction","baseline":0,"threshold":0.01}]
}
```

运行记录：

```json
{
  "schema":"response-capture/1", "id":"candidate", "source":"实际运行记录与版本",
  "conditions":{"camera":"固定测试视角","input_method":"software"},
  "inputs":[{"t_s":0,"action":"fire_pressed"},{"t_s":1,"action":"fire_released"}],
  "fire_end_s":1,
  "samples":[{"t_s":0,"yaw":0},{"t_s":1,"yaw":0.1},{"t_s":2,"yaw":0}]
}
```

示例数值只说明格式。秒数从同一个输入起点计算。每个通道给出自己的单位、中性值、恢复容差及职责；原日志缺少的通道不补零。原始文件哈希、转换方式和操作脚本版本保存在项目适配记录中。

## 分层与比较

分别采集源动作、程序化枪身位移/旋转、会影响射向的武器与视角运动、纯视觉镜头震动。记录实际消费者和开关；关闭一层后复测命中射线及可见效果，不能只看配置值。

工具给出范围、峰值、开火结束前的累积量、均方根、恢复时间及恢复阶段跨过中性位的次数。恢复要求连续保持在容差内；未观察到恢复返回空值，不能填写零秒。采样过慢会漏掉振动，报告最大采样间隔用于判断适用性。

不同算法的定义、参数范围和调校理由仍由战斗策划维护。曲线不同不等于机制不同；随机机制需记录种子并做多次试验。同样输入的实机录像与鼠标操作结果用于最终手感评审。某个项目选中的预设与参数保存在该项目中。

第一/第三人称关键事件可用通用时间轴比较。真正的多人同步需另测服务器规则、客户端预测及网络延迟；单机双视角对照不算联机测试。

## 引擎事件接入

[跨引擎动作记录](../../../adapters/engines/action_timing/README.md) 提供 UE5、Unity、Godot 与网页脚本。它记录离散事件，响应采样工具继续处理逐帧运动曲线。事件输入与动画触发可以关联同一次运行，但不得用固定脚本计划时刻替代实际回调时刻。当前通过 CLI 保留录制副本并比较，使用引擎原生工具修改后重新实测。共享看板没有动作检查与片段编辑页面；[编辑与引擎接入](../../../adapters/engines/action_timing/EDITING.md) 面向自定义客户端开发。
