# 射击反馈的工程接入

按 [后坐与表现定义](../../game-combat-design/references/shooting/recoil-and-presentation.md) 核对现有消费者。名称不同可保留兼容映射，不能让同名开关同时控制不同规则。

## 数据与更新顺序

明确输入基准、规则瞄准偏移、发射采样、纯视觉变换、最终投影和HUD更新的顺序。发射按约定采样当前状态，是否让本发冲量影响本发或下一发须一致；不要混用上一帧武器姿态和当前帧射向。

规则镜头与渲染镜头分开时，使用实际渲染投影计算方向提示。第三人称不能通过已经含纯视觉震动的缓存视图反向生成权威射线。装饰性枪械位移不改变发射原点和遮挡判定；需要真实枪口阻挡时使用校准的规则挂点及两段检测。

Gun kick 与视觉枪械后坐分开配置、开关和采样。原手臂动作、枪械自身动作、镜头动作分别审计；关闭源射击动画应覆盖已声明的源动作层，机械部件动画若例外保留须单独标明。程序化与动画不能重复施加同一后坐。

## 稳定性与状态

曲线使用秒作为时基，按实际射速处理重触发；弹簧采用稳定积分或受限子步。变化帧率下验证幅度、射击间隔和恢复时间，固定帧演示不能证明运行稳定。展示与弹道使用独立随机源。

为取消、换弹、奔跑、切换预设、切镜头、暂停和重生定义清理/保留规则，避免残留冲量或意外开火。可调配置校验有限数值、单位和合法范围；非法配置保留可操作的错误提示与安全缺省值。

## 联机项目

仅当本轮有联网需求时，明确服务器认可的动作/射击状态，复制动作标识、时间和必要参数，处理预测、校正、重复事件与晚加入。第一/第三人称分别表现同一规则；本机切镜头不等于联机同步验收。不因反馈修改自动引入联网架构。

## 观察出口

提供适用的层开关、瞄准基准/瞄具/射线/落点显示，采样实际求值的模型与发射记录。预期数学轨迹只能作对照，不能替代真实引擎输出。视听品质与真人手感依 [反馈验证](../../game-prototype-validation/references/shooting-feedback-validation.md) 分别记录。
