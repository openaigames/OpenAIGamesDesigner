# 专业 Skill 与安装包入口

[English](README.md) | [简体中文](README.zh-CN.md)

项目包含 16 个专业 Skill。每个 SKILL.md 是该职业的执行入口，参考资料与脚本保存在对应目录；按任务组合使用，无需为每个职业启动一个独立 Agent。

本文件在分发包中成为包根 README。新装时复制完整包，包含根 LICENSE 和 game-preproduction/runtime；更新已有安装先比较、备份，见 [安装说明](../docs/INSTALLATION.zh-CN.md)。公共命令在安装后的 game-preproduction/runtime 执行；源码维护者从仓库根执行。
