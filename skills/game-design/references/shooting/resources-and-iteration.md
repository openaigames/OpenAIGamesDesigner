# 射击资源、节奏与诊断

共享资源及实验方法分别见 [资源方法](../shared/resources-and-progression.md)、[迭代方法](../shared/pacing-and-iteration.md)。本篇只补射击/发射行为的状态与观察，不要求所有项目有弹药或换弹。

## 连续行为与资源状态

实际采用弹匣、备弹、能量、蓄力、充能或过热时，定义它们的含义、容量、来源、消耗时点、恢复与耗尽反馈。每次请求、实际发射、每个弹丸分别扣资源会产生不同规则，不能混用。

换弹或补充明确启动条件、完成/分段生效、能否打断、剩余资源处理、切换工具后是否继续，以及空仓和未空仓是否不同。需要膛内弹、丢弃弹匣或单颗装填才展开这些项；默认不要为简单原型引入全部模拟细节。

改变射击间隔可能影响输入采样、动画/音效叠加、资源耗尽和换弹占比。改变弹匣容量可能改变输出窗口而不改变单发伤害；伤害与对抗关系引用战斗参考。

## 按症状区分问题

| 症状 | 候选检查 |
| --- | --- |
| 按了但没发射 | 输入是否收到、条件阻断、资源/冷却状态、缓冲消费 |
| 发射了但感觉慢 | 请求到反馈、实际发射间隔、飞行时间与确认延迟 |
| 换弹后数量不对 | 转移时点、打断分支、上限与并发状态变化 |
| 连射才出问题 | 累积偏差、事件频率、状态恢复、音效/VFX 残留 |

先通过证据区分原因，不能把“射击慢”统一解释成提高射速。明确的参数修改则按范围实施，报告适用影响即可，不重做游戏定位。

交付状态/资源规则、实际参数入口、场景和观察依据，必要时检查按住/释放、资源边界、连续补充、切换与取消。工具结果只能证明覆盖行为；手感需要实际操作。只要求改反馈时不擅改战斗强度。
