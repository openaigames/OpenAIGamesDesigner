# 探索活动、接续与迭代

探索可能连接叙事、经营、解谜、表达、建造或战斗，也可以自身构成主要体验。活动数量不等于丰富度，先按 [系统关系](../shared/experience-and-systems.md) 和 [共享迭代](../shared/pacing-and-iteration.md) 分析联系。

## 组织活动而不套固定循环

明确每项活动的进入条件、玩家行动、结果、退出和对后续选择的影响。连接可以是材料、知识、人物态度、世界状态或新的目的。单向剧情推进、重复经营、自由漫游可以并存，但不能假定必须回到同一基地才能成立。

主要活动与偶发内容可以有不同作用。可选故事、景观或短暂小游戏无需都产出货币，但需要合理的可发现性和接续。重复操作若不带来新选择、理解或目标，检查是否只是在填充路径。

## 风险、密度与节奏

按项目目标决定是否有时间压力、资源约束、失败或损失，使用 [信息与风险](../shared/information-and-risk.md)。轻松探索可以没有死亡和资源耗尽；冒险感也可来自未知、关系与不可逆决定。

内容密度取决于移动、观察和理解需要，不是单位面积事件越多越好。连续强提示可能让玩家只执行清单；长空白也可能承担气氛或方向辨认。用具体区域和操作分析目的，不凭类别断言何种密度正确。

## 代表诊断

| 反馈 | 先区分的问题 |
| --- | --- |
| 不知道干什么 | 目标不清、没有可感知机会，还是有意自主但缺少理解依据 |
| 一直迷路 | 定位、路线连接、线索矛盾、记忆或操作问题 |
| 找到了也没意思 | 发现本身、后果用途、反馈或预期落差 |
| 探索和另一活动割裂 | 成果没有改变选择、联系未表达，还是转换负担过高 |
| 回头路很烦 | 返回的意义、重复成本与世界变化是否成立 |

将候选原因与事实分开。测试可观察玩家注意、解释、路线、改变目标和利用发现的过程；完成率和停留时间各有多种解释。不要把快速通过必然视为无聊，或长时间徘徊必然视为投入。

交付局部活动与关系、代表场景、风险/节奏假设、观察方法和结果。明确玩家对地图的既有知识、提示干预与版本条件；文字草案、自动可达检查和真人探索分别提供不同证据。
