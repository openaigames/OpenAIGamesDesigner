# 射击与发射机制：参考入口

用于瞄准、发射、命中、射击反馈、武器操控或相关资源规则。它是专业方法，不是游戏类型；不预设第一人称、现代枪械、竞技对战、伤害击杀或联网。弓箭、投射工具、信号弹等只借用适用方法，不强制转换成枪械系统。

先按 [设计推理入口](design-reasoning.md) 确认用户要改善什么。局部反馈调整不重做全部武器；没有对抗的靶场或发射交互不必加载战斗。需要攻击、防御、伤害或敌人规则时引用 [战斗参考](combat-design.md)，不另建一套结算与状态标准。

| 问题 | 按需读取 | 交付重点 |
| --- | --- | --- |
| 瞄准、目标获取、视角与辅助 | [瞄准与目标](shooting/aiming-and-targeting.md) | 意图、空间/信息、瞄准与目标规则 |
| 发射、轨迹、碰撞与结果 | [发射与命中](shooting/firing-and-hit-behavior.md) | 事件链、判定约定与边界 |
| 后坐、散布、操控与反馈 | [操控与反馈](shooting/handling-and-feedback.md) | 行为与表现关系、可调入口 |
| 弹药、换弹、连续射击与节奏 | [资源与调试](shooting/resources-and-iteration.md) | 状态/资源规则、诊断与回归 |

整体射击设计要连接目标获取、准备/发射、命中结果与下一次行动，解释其在项目中的作用。能开火不代表射击体验成立；没有伤害也可以有精度、轨迹、时机或空间选择。

已有规格优先。若需要独立文件可使用工具包 `templates/feature-spec.md`，按本参考细化瞄准、发射、轨迹、操控与结果；它不要求所有字段都适用。参数按权威配置引用，技术实现以实际引擎为准，运行和体验证据分别记录。
