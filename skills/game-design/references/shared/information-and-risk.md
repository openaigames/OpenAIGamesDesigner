# 信息、选择、不确定性与风险

用于玩家“为何选择、能否理解、是否愿意继续”的设计问题。选择可以偏表达、推理、探索或执行，不必都是收益最大化。

## 信息如何支持行动

区分玩家可观察、可推断、需要调查和有意隐藏的信息；明确何时出现、通过什么载体传达、何时更新或失效。保留未知可以带来好奇或紧张，但选择所需信息不足也可能只是不可理解。

比较选项的结果、代价、承诺与可逆性，并检查玩家如何在行动前感知差异。没有实际不同后果的选项可以用于表达，但不应声称具有策略取舍。内容既可奖励熟练，也可支持不同偏好，不要求所有选择强度完全相同。

## 风险并不等同于死亡掉落

按项目定义失败或不确定后果：时间、路线、关系、机会、已取得成果、暴露或状态变化。说明后果由什么引起、何时结算、怎样避免/缓解/恢复、是否有不可逆部分。不要从“探索”“撤离”“冒险”自动加入全部损失或生存条。

区分世界/事件的不确定性、信息不足、操作失败与实现错误。玩家可能接受未知结果，但不代表能接受规则或反馈前后矛盾。随机性需说明影响什么选择、如何防止不符合目标的极端组合；固定场景也可以通过信息和选择产生变化。

## 常见问题与取证

- 玩家不愿继续：可能因为剩余机会不明、累积损失过大、任务已完成，或继续没有新选择，不能直接提高奖励。
- 玩家总选安全项：可能符合轻松体验目标，也可能因风险收益表达失衡；先确认目标。
- 玩家反复失败但没有学习：检查原因反馈、可推断线索、恢复成本与是否真的有可行选择。

例：一个封闭洞口提示“这里可能通往更短路线”，和提示“这里必有稀有宝箱”会吸引不同动机。前者可围绕导航知识设计，后者涉及成果价值与预期；二者不能只当作换了一段提示文字。

交付信息与选择关系、可知/未知边界、后果及恢复规则、候选取舍和验证问题。依据观察区分未知与不清晰，不能用增加 UI 提示作为所有信息问题的默认答案。
