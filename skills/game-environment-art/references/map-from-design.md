# 地图制作与空间交接

用于新地图、按图重建或修复“模型与已选设计不像”。先明确本轮在探索空间、确定外观、制作已有方案，还是修复局部差异。沿用有效成果，从当前问题进入，不为补流程重做整图。

空间尚未确定时，按 [地图规划与迭代](../../game-level-design/references/map-planning-and-iteration.md) 选择草图、视图和原型；已选图纸或布局则成为制作输入。视觉探索可以并行，只要求概念或草图时交付该范围。表达方式与迭代次序由项目决定，效果图、俯视图和全图灰盒都不是所有任务的必经首稿。

## 1. 核对题材与表现方向

题材、地域和建筑用途不能代替视觉风格的选择。制作设计图时尽早核对方向；**进入依赖风格的建模、资产生成或材质制作前，若没有明确的用户选择、现有有效规范或风格选型委托，必须询问**。围绕当前任务给出少量有区别的表现选项，允许用户用自己的描述确定方向。

已有选择直接沿用，不重复问；输入冲突只询问冲突部分。资源不足时说明缺口并用局部样板验证可行做法，不自行改变已选风格。用于尺度或规则试验的白模仅记录为占位状态。

在现有 Art Direction 或地图规格中记录：题材与风格、形体/材质/细节与光照目标、用户已定和委托选择的部分。若本项目采用参考，写清实际选用版本和用途；不从工具包注入默认作品、地域、布局或风格。

## 2. 对齐空间依据与视觉方案

先说明图或原型要支持什么判断。平面连接、跨层空间、大尺度区域、状态变化可以采用不同表达；按当前问题记录有效边界、路径、目标或活动区、尺度与待测位置，不要求每种地图都有出生点、战斗路线或掩体。

要判断几何时，图纸应能区分实体、空隙和连接，并说明尺度依据；只讨论拓扑或活动关系时允许先用关系图。空间试验使用影响结论的实际能力、镜头与规则，记录占位带来的限制。外观选定与空间验证各有依据，不能互相代替。

美术与关卡一起评估体块、地标、材质分区等选择对本项目活动的影响。保存当前空间与视觉方案的版本和必须保留的关系；视觉图里缺少的结构、尺度或背面是待设计内容，不能宣称已从透视画面恢复出唯一答案。

## 3. 为下一步制作补图纸

按尚未明确的结构选择视图，已有源数据足够时直接使用。用户要求“各角度平面图”时，提供能核对相应空间的正投影或剖面，不把斜俯视插画当作正投影。

| 要核对的内容 | 可采用的图纸 |
| --- | --- |
| 区域分布、地形和大尺度连接 | 区域总图、地形与尺度图 |
| 占地、边界、平面路径与入口 | 总平面或局部平面 |
| 层间连接、坡度、地下与遮挡结构 | 分层图、标高图、剖面或局部空间图 |
| 可见轮廓、层数和立面构成 | 必要方向的立面与局部详图 |

无需为凑数量补齐四面立面，也不要求地形或大世界按建筑图纸组织。各图共享有效对象标识、单位、坐标、尺度与版本，标清观察方向；尽量从同一空间数据或原型派生。独立制作的多图须核对结构、连接、数量和高低差的一致性。

可见结构、推定连接、建议尺寸分别标明。对照选定输入展示差异及影响制作的待决项。用户要求“核对后再推进”时等待对应反馈；“按这些图继续建模”可作为进入制作的授权，不重复确认。

旧模型被指出不像时，回到已选输入找差异，不能把旧模型的投影重标为设计依据来证明它正确。

## 4. 制作代表区域并校准

扩大制作前沿用目标设备、引擎版本、画质与性能条件；缺口会改变方案时再询问或在有效委托内选择。回读有效图纸与风格版本，明确单位转换、坐标、原点、对象标识、实际镜头和交互尺度。

选择能暴露当前风险的局部，检查几何与连接、代表材质和光照，再扩大同类制作；已有有效样板无需重做。区域大小和内容由待验证问题决定，不固定为某种建筑或道路组合。用可比较视图检查空间差异，并在实际镜头与活动中检查形体和表现。

写实目标涉及真实比例、结构厚度、关键轮廓、合理表面和纹理尺度，以及光照下的接地和空间关系；不能只增加面数或换 shader。其他风格按其已选规则检查。低面数、实例与 LOD 是资源方法，不能据此改变已选表现方向。

代表区域同时核对几何、材质、贴图、碰撞及适用的加载开销，参见 [地图性能与资源处理](../../game-technical-art/references/map-performance.md)。UE 资产可先只读审计，再按类别生成传统 LOD 或配置 Nanite 派生副本；验证保存后的读回和实际视点，再扩展同类资产。设置值或减面比例不能代替实测性能。

## 5. 扩展、导入与回归

依照已检查的模块、材质与摆放规则扩展；程序生成保留可编辑源、种子和输入版本。分开管理可见几何、碰撞与装饰，重复资产按用途实例化。导入后核对单位/轴向、依赖、实际消费者和相关运行状态。

交付关联有效的草图/原型、视觉方案、必要图纸、可编辑模型及引擎场景。对照空间关系后，用项目支持的移动和活动检查受影响区域；视线、通行、状态或资源开销变化时回测原假设。大尺度扩展还需检查区域间联系，局部样板不代表全图已通过。

导入成功、图纸一致、运行检查、性能测量和用户认可分别记录。继续使用现有资产规格、任务和验证入口；缺少输入或工具时写清具体限制，不把流程文字、静态渲染或局部样板报告为整图已完成。
