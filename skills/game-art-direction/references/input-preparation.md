# 生成输入准备

当资产要求需要转换成 Tripo、混元、图像、视频或音频输入时，使用[输入准备工具](../../../adapters/assets/input-preparation.zh-CN.md)。沿用既有清单与规格，不为局部生成重做项目方向。

将用户原始要求保留为 brief，提取必须保留项、偏好和技术条件。可比较属性使用同一 attribute 和相同单位，不凭外观猜测尺寸。提取和改写由当前 Agent 完成，工具负责拼装与检查，未调用额外语言模型。

按实际适配器能力逐条选择 prompt、reference、postprocess 或 unresolved，逐份参考说明是否发送。实际看过图片才能填写 reference.evidence；遮挡、不明左右或不可见结构保留缺口。参考职责仅在本地记录，不能假定服务知道哪些特征应继承。支持文字时将重要区别写进实际提示词。

改写组织对象、结构、材质与视角等已有信息，保留用户语言、风格、模型和输入选择。需要改变时沿用已有授权，不从“优化提示词”推断新授权。尺寸、拓扑和游戏接口不能仅靠文字保证；有实际处理方法时登记操作与验收标准，否则保留 unresolved。

核对完整 brief 是否落实到输入或后续处理、约束有无遗漏、有无擅加特征、参考职责是否正确。按实际观察填写 plan.review 的核对项、执行者和理由；这是 Agent 工作记录，不要求用户逐项审批。示例 false 不能批量改为 true 代替评审。生成输出质量仍未检查。

运行 prepare 后核对 preview.md 的差异、真实发送文字、图片选择、待验收项和参数。修复错误，再通过 asset_workflow 原提交入口排队。输入变化重新准备，不改冻结记录或删除 preparation 链接规避检查。保留逐任务付费授权和恢复原远端任务的规则。生成后继续按[素材质检](generated-asset-review.md)检查实际输出。
