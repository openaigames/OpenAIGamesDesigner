# 生成与外部素材的筛选、修订和接入准备

适用于 AI 生成、素材库或外包返回的文件。制作入口沿用 [资产执行](asset-execution.md)，形式规格见 [制作规格](asset-production-specs.md)。本篇不选择服务，也不把候选图当成模型、骨架或可直接使用的游戏资源。

## 生成前把要求分层

把需求拆为必须保持的身份/功能约束、可比较的艺术变量、真实格式与依赖、当前不要求的内容。示例：同一敌人的轮廓与挂点必须保持，装甲磨损可变；如果任务只是正面概念图，不要求伪造背面几何或完整动画。

输入包括实际参考文件、其使用依据、局部制作要求和消费者场景。提示词只能覆盖服务支持的部分，剩余规格需由后处理或人工制作完成。记录真实工具/模型版本、输入版本、参数与任务编号；同一 seed 不足以保证不同版本或设备得到相同结果。

使用 Moodboard 时按 [图板到生图的交接](moodboard-and-palette.md#写入-art-direction-与后续生图) 读取适用主题/资产板及最近已保存、选用的色板，为每张输入图注明参考职责。绑定实际传入文件、图板版本与当前 HEX/色彩角色；色值表或 HTML 链接不等于工具收到图片。质检对照此次输入快照，检查用户改色、资产身份与全局风格是否保留，不改用之后更新的图板倒推本次要求。

## 分阶段筛选

先检查用途不成立或无法使用的问题，再比较风格偏好，避免因精美而忽视不可交付项。

| 检查层 | 需要看的材料 | 处理方式 |
| --- | --- | --- |
| 文件与依赖 | 可打开原文件、实际尺寸/声道/模型数据、依赖清单 | 损坏或缺依赖先修复；扩展名检查不能替代解码 |
| 身份与结构 | 实际视角、关键轮廓、持物/关节/开口等用途相关区域 | 标注具体失真位置，判断局部修订还是重做 |
| 风格一致性 | 与认可基线同尺寸、同背景或同照明比较 | 区分轮廓、细节、明暗和材质问题，不只给一个总分 |
| 体验与表达 | 方向摘要、适用图板版本，以及本轮真实画面/动态/声音 | 检查目标感受与玩家判断是否成立；指出具体冲突，不能用精细程度替代方向判断 |
| 使用质量 | 引擎内缩放、运动、拼接、动画或实际监听 | 发现图集边缘、接缝、穿插、循环点击声等再返修 |

不把所有检查套到所有资产；音频不能依靠图像观察评价，单视图不能确认背部结构，静态模型不能证明可变形。

## 修订循环

一次修订指定缺陷位置、应保持的部分、预期变化和复查条件。保存原候选和修订输入，避免每轮重生成整个对象导致身份漂移。多帧或多视角资产用接地线、关键结构、色块与挂点对照；逐张好看不证明连续播放稳定。

例：三张角色候选中 A 轮廓符合但边缘有光晕，B 细节丰富但手部遮挡武器挂点，C 风格不一致。如果光晕经真实透明底与采样检查可修，A 可能更接近交付；不能仅按单图精细度选 B。修复 A 后仍需在游戏背景复查，不将后处理成功自动升级为角色验收通过。

重复尝试没有解决结构约束时，应考虑局部编辑、人工修正、改变输入表达或换制作路线；用已有授权和本轮时间/成本范围决定是否继续，不默认无限重试或调用付费服务。

交付选定版本、淘汰/修订理由、任务和来源链、可编辑文件与运行资源、剩余人工工作。来源说明保留真实材料，不从“由 AI 生成”或“能下载”推断授权；法律结论不由本参考代替。质量结果绑定具体文件版本和消费者场景，后续替换要复核受影响项。
