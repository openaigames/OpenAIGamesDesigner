# 资产制作与变更交接

支持新增、修改、替换和移除资产。先分清方向探索、制作规格、实际制作、引擎集成或质检；用户仅要一个图标时不重做全套风格规范。

## 读取现有视觉与消费者

查看相关资产、游戏内画面、现有风格规则、文件与导入设置，以及使用该资产的对象/场景/UI。用户要求沿用的角色身份、品牌、颜色和工程约束是本轮条件。没有真实图像时只讨论文字要求，不伪称已核对一致性。

新资产优先适配项目现有尺度、构图和制作方式。风格整体转向才比较新方向；已有认可目标能继续使用，不每次重新确认。局部替换区分共享源文件、具体实例和派生资源，避免为一个场景修改全项目公共材质。

当前角色、场景或物件需要专属参考且缺少适用图板时，先按 [制作意愿与风格确认](moodboard-and-palette.md#先询问是否制作再确定风格) 询问是否建立资产 Moodboard，得到同意并确定本轮风格后制作，关联既有主题板并说明继承与局部差异。用户已明确要求则沿用，不重复询问；拒绝或暂缓时记录决定。已有足够参考则沿用，不把新建图板变成每次资产变更的前置条件；局部配色调整只更新适用资产及其参考版本。

## 资产交付单

需要把用途转成具体约束时读 [角色、环境与材质规格](asset-production-specs.md)；跨资产不一致读 [风格生产](style-production.md)；生成或外部返回素材的筛选与返修读 [候选质检](generated-asset-review.md)。以下类型表是交接入口，不替代这些制作方法。

替换占位或补齐模型、动作、VFX 等资源时，按 [素材检索与获取](asset-sourcing.md) 检查现有资源与外部候选，比较复用、修改和制作的成本。沿用已确定风格、来源限制与选材委托，按本轮消费者核对配套依赖，不因局部补素材重开整套方向讨论。

需要独立交付时使用工具包 `templates/asset-spec.md`，实际质检记录可使用 `templates/validation-report.md`；已有项目格式优先。

使用现有资产清单/任务；没有时在本轮规格中记录用途、消费者、源文件/输出位置、必要格式与尺寸、关联版本/来源、制作方式、验收条件。数量和尺寸依据实际用途，不能因模板需要填任意值。来源许可未知如实记录，参考图不自动成为可使用资产。

记录格式沿用 [资产与动作记录表](outputs.md#资产与动作记录表)：用表格承载资源、来源、消费者与分阶段状态，说明段落解释取舍和限制。替换时更新对应条目及引用；旧资源的使用或废弃状态单独保留，不能因整理格式把候选升格为已采用。

| 类型 | 按需要核对的制作与接入约束 |
| --- | --- |
| 2D 精灵/贴图 | 游戏内尺寸、像素密度、透明边缘、锚点、图集布局、采样与压缩、碰撞/遮罩依赖 |
| UI/图标 | 实际显示尺寸、状态、焦点/选中表达、文字区域、对比与缩放、切片边界 |
| 3D 模型/材质 | 单位、坐标/朝向、比例、原点、材质槽、贴图通道、碰撞与细节级别（需要时） |
| 动画 | 2D 帧序列或骨骼约束、循环/过渡、根运动（适用时）、挂点、关键事件与取消时序 |
| VFX | 触发/结束事件、空间与挂点、持续时间、层级/遮挡、密集场景可读性和性能预算 |
| 音效/音乐 | 事件用途、时长/循环、格式、声道、响度与混音角色、触发及停止条件；实际听过才能评价效果 |

需要制定风格规范时，优先记录本轮会用到的色彩、剪影、材质、细节密度、角色/环境比例、UI 和反馈语言，并配真实目标或明确待补参考，不机械填满艺术手册。

## 替换与验证

替换前检查标识、路径、图集索引、骨骼/挂点、动画事件、材质或音效引用等真实依赖。保持引用稳定或列出迁移工作；不只改文件名就认为完成集成。默认使用项目已有生成/导入工具；工具缺失时输出可交接规格，不编造资产。

分别记录：候选已生成/取得、方向已选择、源文件质量检查、引擎已导入、运行效果已检查。实际接入在用户授权任务内完成，不要求每个普通资产多走一次审批；整体风格等尚未决定的方向则保留候选。

检查至少覆盖本轮用途及直接受影响的共享场景：缩略图好看不证明游戏内可读；静态截图不能验证动画、声音或 VFX 生命周期。按实际风险使用运行画面、录屏、监听或性能数据。旧版本、人工源文件和导入配置按项目版本方式保留，只有确实可恢复才声称可回退。

交付时链接实际资产与消费者，注明修改和验证范围、已知限制，以及技术侧仍需完成的接入。不要把艺术质量通过记为功能规则通过。

## 看板使用中的资产变更

新增、替换或导入后，若项目已启用看板记录区，按 [项目看板与美术清单](../../game-preproduction/references/project-workbench.md) 运行文件核查，补回已发生的事实及有依据的对象归属。仅浏览不自动写回；新增文件不默认继承相似名称的标签，版本变化和未知用途保留复核状态。
