# 从作者源到实际消费者的技术美术处理

## 先建立原始依据

保存源文件版本、工具/引擎版本及作者示例。原生 UE Content 在新工程打开只证明该环境下的原资源表现，不能声称复现作者完整工程。分别检查编辑态与运行态组件，找到真实 SkeletalMesh、骨架、动画、附件和创建来源。

外部制作先检查单位/轴向、层级、参考姿态、根运动、蒙皮与导出设置，做代表样本回传后再扩展。已有原生资源直接检查实际绑定、混合和消费者；只改挂点或事件时保留改前/改后及受影响片段，不伪造 Blender 回传记录。

## 骨架、蒙皮与附件

按变形意图验证骨链长度、参考姿态和权重，关注关节极限与扭转。重定向会改变接触和根位移，不能只看骨架名称相同就判断兼容。测量数据取实际求值后的骨骼，注明 IK/动画层/坐标与变速。

附件配置区分骨骼、插槽、测量标记与真正武器组件；来源不明时停止采用惯常骨名。比较相对位置、相对旋转、握柄方向及世界运动，单纯位置误差小可能仍握反。副手只在声明的握持区间比较接触，释放、换手和收招使用不同约束；手腕接近握柄不自动证明手指自然。

问题按源动作/蒙皮、转换、重定向、附着、IK、混合控制和表现时序定位。隔离观察后回到实际控制链，不用测试场静态姿态代替连续交战。自定义骨架或无武器动作可声明相应检查不适用，必须有原因，不填假命中点。

## 材质、规格与性能

读取实际单位/尺度、贴图色彩空间、法线方向、透明方式、材质编译与依赖。将显示错误和设计风格问题分开；技术读回正确后仍可能需要作者修正造型或照明。

性能在目标构建与环境检查，定位纹理/材质、蒙皮、几何、透明覆盖、阴影或资源加载成本。优化保持规格消费者一致，记录改动影响的镜头和动作；不能用编辑器截图的帧间隔当 GPU 性能。

## 交接与失效

输出原件引用、派生资源、处理配置、实际绑定与消费者、版本化证据和未覆盖项。依赖变化只使受影响判断需复核；当前结论入口更新，旧报告保留其适用版本。

共享引擎执行器管理本任务会话和运行，项目导出接口处理不能通用推断的复杂对象。工具能力不够时说明具体缺口并完成独立工作，不重写另一套 UE 启动器，也不冒称解析了任意 AnimBP。
