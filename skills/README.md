# Specialist Skills

[English](README.md) | [简体中文](README.zh-CN.md)

The toolkit includes 16 specialist skills. Each `SKILL.md` provides instructions for the agent, with supporting references and scripts in the same directory. Combine skills to suit the task; each discipline does not require a separate agent. The linked skill instructions and specialist references are written in Simplified Chinese.

For a fresh installation, copy the complete bundle, including its root LICENSE and `game-preproduction/runtime`. Compare files and back up local changes before updating; see [installation](../docs/INSTALLATION.md). Run shared commands from the installed runtime, or from the repository root when using source.
