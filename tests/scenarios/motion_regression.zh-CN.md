# 第二来源动作与综合回归

[English](motion_regression.md) | [简体中文](motion_regression.zh-CN.md)

本案例配合 `motion_regression_audit.py`，复用 `motion_layers_audit.py` 的坐标和记录格式适配。它是明确约定的技术案例验收器，不是任意动画的通用审美评分器。

## 输入与实际消费者

- 两个真实蒙皮角色：CesiumMan、RiggedFigure；各自保留原始资产、目标骨架、权重和显式角色配置。
- 来源一：自制技术动作。来源二：已有 CesiumMan 原始公开动画的 1.9 秒内部区间，实际从 24 Hz 子帧求值并重采样到 30 Hz。不是完整无缝循环，也不是新获取的动捕库。
- 独立重定向后的 `external_gait`，58 帧；`full_external` 绑定它，非循环，事件为 start=0、pulse=0.65、finish=1.9 秒。
- 同一目标角色的多个加工结果由项目脚本核对骨架、角色映射、依赖、导出件和哈希后组成集合。合并需要项目脚本显式处理。
- Godot 4.7.2 原生 AnimationTree，以及 UE 5.8.2 原生 AnimBP；可编辑工程和打包 Windows 程序都执行。

## 12.4 秒场景

| 时刻 | 行为 |
| --- | --- |
| 0.5 秒 | 全身播放新动作，正常速度 |
| 3.5–5.9 秒 | 控制器前移 |
| 3.6 秒 | 移动中上半身播放同一动作 |
| 7 秒 | 全身以 0.5 倍速播放 |
| 11 秒 / 11.25 秒 | 再触发全身动作 / 取消 |

独立基线使用同样的时步、控制器和移动路径，不触发动作层。分别执行固定 60 Hz 和真实交替 30/60 Hz 物理步长。基线必须跟随一致的采样时间，不能复制被测记录当基线。

```text
python tests/scenarios/motion_regression_audit.py runtime.json baseline.json external-revision bindings.json
```

验收器比较完整权重时的原生骨骼与 DCC 原始捕获，位置阈值 2 mm，旋转变化角度大小阈值 0.2°；上半身遮罩外位置差小于 0.1 mm、旋转差小于 0.02°。旋转角度大小匹配不单独证明旋转轴或皮肤品质；还需实际正面、侧面画面。输出相邻 `audit.json` 和非零失败退出码。

检查四次接受请求、一次取消、事件顺序/重复/时刻、最终权重清理、实际资源别名和变帧率。错误时间、重复事件、残留权重、错误骨位的报告篡改，仅用于证明验收器会拒绝，须和真实管线负例分别统计。

## 资产替换与负例

每工程先运行旧别名绑定，再将新集合 stage、原生导入、activate，并重新打包。验证导入前激活、导入后修改绑定、导入后修改源导出件均被拒绝且当前绑定不变。保留旧目录和失败证据。

加工负例：左右映射、前向、非均匀比例、缺目标依赖；绑定负例：事件超出片段；项目尺寸合同：实际蒙皮高度 1.8 ± 0.036 m。等比放大 100 倍必须用该项目尺度合同发现，不应杜撰普适身高限制。历史反向抬臂源捕获继续作为已知失败样本。

## 成本与实际输入

预先固定 1/16 角色，各两遍，顺序 1/16/16/1；实际渲染 1152×720，预热 5 秒后采样 15 秒。停用截图和逐帧骨骼大报告，以真实墙钟、原生实例见证和系统进程 CPU/内存计量。实例数量、唯一动画对象、错开相位和时钟错误必须检查。报告分位数、尾部、构建、硬件、渲染器；不同引擎渲染设置不能直接排名。

实际窗口输入另行执行，禁止同时跑成本测量。记录是助手操作还是人类试玩，区分按键轻点、持续输入和程序回放；没有观察到的操作不记为覆盖。取消残留和持续转向可以由已有自动回归补充，但不能冒充实际窗口操作。

本机自动输入的已知限制：Godot 收到正确的逻辑键值，但物理键身份错误地成为 Pause；独立测试入口显式使用逻辑键以验证 OS 窗口路径，生产模板默认物理键保持不变。持续按下/松开的路径分别由 Godot `Input.parse_input_event`、UE `APlayerController::InputKey` 测试，避免直接设置移动愿望或调用动作处理器。UE 第一轮在转身锁定期请求跳跃被拒绝，正例必须放在可跳跃的状态中。实际 OS 短脉冲与引擎注入必须分别标识。

## 范围边界

公开步态用于传输与播放验证，不保证脚接触、循环接缝或具体游戏的最终动作品质。根运动和接触约束使用各自的验证入口。
