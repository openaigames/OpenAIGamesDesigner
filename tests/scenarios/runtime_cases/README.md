# Native Runtime Regression Recipes

[English](README.md) | [简体中文](README.zh-CN.md)

Create isolated Godot or UE examples through the [runtime component tools](../../../adapters/engines/runtime_components/README.md). Use `runtime_validation.py` to run the generated scenarios with the engine installations and output directories you specify.

Cover installation into an existing project, repeated installation, preservation of local edits, input focus and pause, interaction cancellation, save/load, scene changes, and cleanup. Test updates and rollback in a disposable copy using the [installation guide](../../../docs/INSTALLATION.md).

Retain commands, native reports, logs, source revisions, and observed failures. Inspect reports as well as process exit codes. Test physical devices and manual gameplay separately from programmatic input. See the [validation guide](../../README.md) for evidence and completion criteria.
