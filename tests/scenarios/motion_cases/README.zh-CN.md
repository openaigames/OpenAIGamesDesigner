# 动作处理回归用例

[English](README.md) | [简体中文](README.zh-CN.md)

使用[动作处理工具](../../../adapters/processing/MOTION.zh-CN.md)创建隔离的角色与动画修订，再通过[原生采样](../../../adapters/engines/motion/README.zh-CN.md)验证。为用例配置实际引擎程序、源文件、骨骼映射及输出目录。

| 用例 | 检查内容 |
| --- | --- |
| 不同比例与参考姿势 | 重定向后的关节朝向、可达范围、蒙皮变形与根运动归属 |
| 轴向、单位和对象变换变化 | 导入后的世界尺度、朝向与骨骼采样位置一致 |
| FBX 与 GLB 往返 | 片段、时序、蒙皮、材质及依赖文件得到保留 |
| 骨骼缺失或名称歧义 | 在激活输出前明确拒绝 |
| 修改采样或源修订 | 拒绝过期或不匹配的证据 |

播放接入可使用[多来源回归用例](../motion_regression.zh-CN.md)和[移动用例](../motion_locomotion.zh-CN.md)。保留源快照，对比真实引擎采样，并通过画面检查蒙皮变形及动作自然度。

自动检查见[测试说明](../../README.zh-CN.md)，更新和回滚命令见[安装说明](../../../docs/INSTALLATION.zh-CN.md)。
